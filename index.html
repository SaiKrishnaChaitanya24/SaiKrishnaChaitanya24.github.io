ABOUT THE RELEASE

From raw MRI to research-ready outputs.

The workflow unifies anatomical preprocessing, distortion and motion correction, multimodal registration, region-of-interest analyses, and structural connectivity processing. Its subject-level interface supports reproducible execution on HPC systems with SLURM.

01 / NEUROIMAGING AI◉

NeuroQC-Assist

A human-in-the-loop T1-weighted MRI quality-control prototype. The pipeline uses a 3D convolutional network with an image and brain-mask input, and produces quality scores, PASS / REVIEW / FAIL triage outputs and optional Grad-CAM visualizations.
